# Student Management System using AWS

## Project Overview
The Student Management System is a web-based application developed using PHP and MySQL to manage student records efficiently.

## Features
- Add new student details
- View student records
- Update student information
- Delete student records
- Manage student data using MySQL

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- Amazon EC2
- Amazon RDS
- AWS IAM

## AWS Architecture
- **Amazon EC2:** Hosts the PHP web application.
- **Amazon RDS:** Stores student information using MySQL.
- **AWS IAM:** Manages access permissions to AWS resources.

## Project Files
- `index.php` – Main application page
- `add.php` – Add student details
- `update.php` – Update student details
- `delete.php` – Delete student details
- `db.php` – Database connection
- `style.css` – Application styling

## How to Run Locally
1. Install XAMPP.
2. Start Apache and MySQL.
3. Create a MySQL database named `studentdb`.
4. Import or create the required student table.
5. Place the project folder inside `htdocs`.
6. Open `http://localhost/your-project-folder/` in your browser.
